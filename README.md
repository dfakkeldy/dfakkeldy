### Hi, I'm Dan Fakkeldy

I build software with AI coding agents from rural Nova Scotia. I set the direction, review and gate the work, and own
the release process. The work runs from iOS apps to public-finance analysis. I run [KinNoKi Labs](https://kinnokilabs.com).

  train.
  [Join the TestFlight beta](https://testflight.apple.com/join/Zu9rzg59).
- [**ns-citizens-budget**](https://github.com/dfakkeldy/ns-citizens-budget): a citizen's budget for Nova Scotia
  2027–28. A re-runnable Python model of a path to balance, built from the budget, Public Accounts and Auditor General
  reports, and submitted to the province in October 2026.
