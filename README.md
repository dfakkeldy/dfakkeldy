### Hi, I'm Dan Fakkeldy

I build software with AI coding agents from Cape Breton, Nova Scotia. I set the direction, review and gate the work,
and own the release process. The work runs from iOS apps to public-finance analysis. I run [KinNoKi Labs](https://kinnokilabs.com).

**Start here**

- [**Echo**](https://github.com/dfakkeldy/Echo): an audiobook study player for iPhone and iPad, Apple Watch, Mac and
  CarPlay, with word-level read-along, on-device narration, spaced-repetition flashcards, CI and a nightly → weekly →
  main release train.
  [Join the TestFlight beta](https://testflight.apple.com/join/Zu9rzg59).
- [**MacroMark**](https://github.com/dfakkeldy/MacroMark): Apple Watch voice capture that appends each note to a daily
  Markdown file in iCloud Drive, built with Swift, SwiftUI and App Intents.
  [Free on the App Store](https://apps.apple.com/ca/app/macromark/id6785081218).
- [**ns-citizens-budget**](https://github.com/dfakkeldy/ns-citizens-budget): a citizen's budget for Nova Scotia
  2027–28. A re-runnable Python model of a path to balance, built from the budget, Public Accounts and Auditor General
  reports, and submitted to the province in October 2026.
- [**explainer-audiobooks**](https://github.com/dfakkeldy/explainer-audiobooks): a method and Claude Code skills for
  long, sourced, narration-ready audiobooks, with a public library of finished titles.
